Supported language: integer, boolean, real, Unicode characters and bounded UTF-8 strings, enumerations, subranges, bounded sets, constants, named types, fixed arrays and records, structured control flow, nested procedures/functions, value/reference parameters, read/readln and write/writeln. Integer arithmetic is checked; div/mod require nonnegative dividends and positive divisors. Scalar indexing/updates, slicing, typed pointers and manual allocation are supported. Limits: 256 KiB source, 1 MiB input/output, 64 MiB program memory, 5 seconds per compile/run (input waiting excluded), 64 simultaneous routine calls. Language reference
